## 📂 Featured Project

### [SOC Home Lab — Splunk & Sysmon](https://github.com/adiirmdhn/SOC-Home-Lab-Splunk)

A self-hosted SOC environment built to simulate, detect, and respond to real attack scenarios:

- **Simulated Attacks:** Brute Force (RDP), Phishing, Suspicious PowerShell Execution
- **Detection:** SPL queries, automated alerts, and Splunk dashboards for monitoring
- **Documentation:** Full Incident Reports with timeline, evidence, and MITRE ATT&CK mapping
- **Outcome:** Successfully classified True vs False Positives and defined escalation criteria
