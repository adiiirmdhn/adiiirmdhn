### 🚀 Featured Project

<div align="center">

[![SOC Home Lab](https://github-readme-stats.vercel.app/api/pin/?username=adiiirmdhn&repo=SOC-Home-Lab-Splunk&theme=tokyonight&hide_border=true)](https://github.com/adiiirmdhn/SOC-Home-Lab-Splunk)

</div>

A self-hosted SOC environment for simulating attacks and building the detections that catch them. Each lab is documented like a real incident — alert details, analyst notes, MITRE mapping, and an escalation decision.

| Lab | Attack Simulated | Detection |
|---|---|---|
| Live Attack 1 | Brute Force (RDP) | Splunk SPL correlation on Event 4625 |
| Live Attack 2 | Suspicious PowerShell Execution | Sysmon Event 1 + Splunk detection |
